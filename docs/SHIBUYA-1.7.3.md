# Anime Coil v1.7.3 — Kitsu Eye Fix, Shibuya Arena, Clearer Text

Released locally on 2026-10-02. The user subsequently authorized publication of v1.7.3 to the existing [GPT Site](https://anime-coil-naruto.igrisdeez.chatgpt.site) and [Git main](https://github.com/IgrisDeez/Anime-Coil/tree/main). Existing Site access is preserved.

## Changes

- Normal Kitsu eye groups move forward by **0.035 model units** once during desktop/mobile cache preparation. Blue irises, separate blink transforms, shared geometry/materials, fallback loading, attachment shape, and transformed heads remain intact. Editable assets are unchanged.
- Live review found another source of the apparent eye overlap: replacing imported materials discarded the skin’s double-sided setting. Inward-facing cheek triangles then exposed the orange coil. The cached skin now retains the imported setting. Both changes run only during preparation, add no geometry or draw batches, and leave ordinary rendering/animation timing unchanged.
- Only Shibuya is registered or accepted by environment creation. The Leaf, Tournament, and Harbor builders, their exclusive atmosphere/background actors, minimap/boost/effect palettes, dispatch paths, selector hooks and retired-specific tests are removed. Shared construction components used by Shibuya remain.
- The lobby shows a fixed Shibuya thumbnail and name under Arena. Character selection, Details, mode choices, Play, panel alignment and cosmetics preview are retained.
- Retired/invalid map preferences resolve to Shibuya, including blocked storage. Sprint progress retains only Shibuya. The Starlight challenge is **Finish a 3-minute sprint in Shibuya**, target one; old four-map completions retain their reward and equipped cosmetics. Records and unrelated preferences use their existing storage keys and rules.
- Player-facing copy describes actions and outcomes. Help and Details use the same skill/ultimate descriptions. Mode explanations cover the three-minute timer, respawns, natural-orb scoring, direct/target eliminations, ultimate charge and excluded ultimate scoring. Pause, respawn, results, practice, challenges, cosmetics, loading/errors and metadata use practical wording. Names and gameplay rules remain unchanged.
- Package, lockfile, visible branding, title, Credits and current README identify **v1.7.3**. Historical release documents and prior local changes are preserved.
